# 🌦️ Weather Application

## 📖 Description

Weather Application is a responsive web application that allows users to search for any city and view real-time weather information instantly. The application fetches live weather data using the OpenWeather API and displays important weather details such as temperature, wind speed, city name, and country. The project provides a simple, clean, and user-friendly interface, making it easy for users to access accurate weather information from anywhere.

## ✨ Features

- Search weather by city name
- Real-time weather updates
- Display city and country information
- View current temperature in Celsius
- View wind speed details
- Error handling for invalid city names
- User-friendly interface
- Responsive design for all devices

## 🛠️ Tech Stack

- HTML5
- CSS3
- Tailwind CSS
- JavaScript (ES6+)
- OpenWeather API
- Fetch API
- Responsive Web Design
- Git & GitHub
